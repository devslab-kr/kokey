Privacy Policy · 최종 갱신 / last updated: 2026-08-07

요약

kokey 확장은 어떤 데이터도 수집·저장·전송하지 않습니다. 모든 텍스트 변환은 사용자의 브라우저 안에서만 실행되며, 확장은 네트워크 요청을 전혀 만들지 않습니다.

The kokey extension collects, stores and transmits no data of any kind. All text conversion runs entirely inside your browser; the extension makes no network requests.

수집하는 데이터 / Data we collect

없습니다. 개인 정보, 입력 내용, 방문 기록, 사용 통계, 오류 로그 — 아무것도 수집하지 않습니다.

None. No personal information, no typed content, no browsing history, no usage analytics, no crash reports.

처리 방식 / How processing works

  • 변환은 사용자가 명시적으로 요청할 때(우클릭 메뉴 또는 단축키)만 실행됩니다. Conversion runs only on your explicit action — the context menu or the keyboard shortcut.
  • 변환 대상 텍스트는 메모리 안에서 즉시 변환될 뿐 어디에도 기록되지 않습니다. The text being fixed is converted in memory and never recorded anywhere.
  • 확장에는 원격 코드가 없으며 모든 코드는 패키지에 동봉되어 있습니다. There is no remotely hosted code; every script ships inside the package.

권한 사유 / Why the extension needs its permissions

  • 모든 사이트의 콘텐츠 스크립트 — 사용자가 어떤 사이트의 입력란에서든 교정을 쓸 수 있어야 하기 때문입니다. 명시적 요청 전에는 아무 동작도 하지 않습니다. Content script on all sites: the fixer must be available wherever you type; it stays idle until you invoke it.
  • contextMenus — 우클릭 메뉴 항목 하나를 추가하기 위해서입니다. Adds the single right-click menu entry.
